
# 결과 해석과 시사점

## 1. 분석 결과
### 1-1. 전국 발생 추세

| 구분 | 값 |
|---|---|
| 최신 발생주기 | 2025.6~2026.5 (12개월) |
| 피해고사목 | 약 177만 그루 |
| 총 제거목 | 약 309만 그루 (피해고사목 111만 + 감염우려목 198만) |
| 발생 시군구 | 166개 |
| 심 이상 지역 | 27개 (전국 피해의 81%) |
| 최저점 대비 | 2021년 31만 그루 → 약 5.7배 |

2017~2026년 피해고사목은 감소 국면을 거친 뒤 다시 증가했고, 2024년 일시 감소 후
2025·2026년 재증가했다. 최저점이었던 2021년 대비 약 5.7배 수준이다.

2025년 발표치는 조사기간이 13개월이고 2026년 발표치는 만 단위 반올림값이므로
증감률을 정밀 수치로 제시하지 않고 절대 증감량으로 기재한다.

### 1-2. 자료 검증

| 검증 | 결과 |
|---|---|
| 원자료–공식통계 최대 절대오차 (2016.5~2022.4) | **0.67%** (내부 기준 1.0% 미만) |
| 2022.5~2023.4 원자료 포함률 | **44.6%** → 공간분석 제외 |
| 좌표계 | **EPSG:5186** (축 XY) |
| 좌표계 검증 지표 | 국내범위 100.0% / 폴리곤결합 98.6% / 전체일치 95.5% / 인공요인 제외 일치 99.2% |
| 기관별 최저 일치율 | 75.92% (기준 미만 기관 자료 비중 1.52%) |
| 격자 배정 | 전국 365,194개 전량 배정, 미배정 0개 |

원자료 검증이 확인한 것은 전국 피해고사목 **총량의 정합성**이며 지역별 공간분포의
완전한 대표성은 아니다. 예를 들어 2019.5~2020.4 발생 시군구는 본 분석 122개,
공식 발표 124개로 차이가 있다.

### 1-3. 공간 반복발생

관측피해격자 중 2개 이상 관리주기에 관측된 비율은 다음과 같다.

| 격자 | 반복관측비율 | 역할 |
|---|---|---|
| 10m | 8.0% | 진단용 |
| **100m** | **44.2%** | **주 분석단위** |
| 500m | 66.0% | 민감도 |
| 1km | 72.5% | 민감도 |

100m 분석격자에서 전체 관측 격자의 44.2%가 두 개 이상의 관리주기에 반복 관측되었다.
격자 크기를 500m와 1km로 확대하면 각각 66.0%, 72.5%로 증가한다.
반복관측 비율의 절댓값은 공간 집계단위에 영향을 받지만,
**10m 위치 단위(8.0%)보다 지역 단위에서 반복발생이 뚜렷하다는 결과는
분석 해상도 전반에서 유지된다.**

최근 관리주기(2021.5~2022.4) 100m 격자 구성은 신규 37,552개,
지속 32,613개, 재발 28,985개로,
**기존에 관측된 지역의 재관측이 전체의 62.1%**를 차지한다.

연속 3개 관리주기 이상 관측된 장기지속 격자는 전국 50,279개이며,
상위 10개 시군구가 그중 **78.9%**를 점유한다
(상위: 울산광역시 울주군, 경상북도 포항시 북구, 경상북도 안동시, 제주특별자치도 제주시, 경상북도 구미시 등).

### 1-4. 지역별 지표

- 누적 피해부담 상위 15개 중 **5개**는 절대 건수 상위 15에 포함되지 않는다.
  절대 규모와 면적 대비 부담이 가리키는 지역이 다르다.
- 관측피해격자 반복관측비율 순위는 격자 30개 이상 지역
  103개를 대상으로 산출했다.
- 누적 피해부담 순위는 소나무류 300ha 이상, 누적 1000건 이상
  58개 지역을 대상으로 산출했다.

### 1-5. 피해등급

공식 시군구별 등급표를 확보하지 못해 최신 등급 기반 분석과 현재·과거 중첩 분석은 실행하지 않았다. 과거 반복관측 지표는 등급 입력과 독립적으로 산출하였다.

## 2. 시사점

### 2-1. 방제 전략

**신규 확산 차단만으로는 부족하다.** 최근 관리주기 100m 격자의 62.1%가
과거에 이미 관측된 지역에서 다시 발생했다. 신규 발생지 대응과 별도로
**반복발생 지역에 대한 지속 관리 체계**가 필요하다.

**피해가 소수 지역에 집중되어 있다.** 심 이상 27개 지역이 전국 피해의
81%를 차지하고, 장기지속 격자의 78.9%가
상위 10개 시군구에 몰려 있다. 균등 배분보다 **집중 투입**의 효율이 높은 구조다.

### 2-2. 지원 우선순위 설계

단일 지표로 순위를 정하면 지역 특성이 가려진다. 최소 세 축을 함께 봐야 한다.

| 축 | 지표 | 의미 |
|---|---|---|
| 규모 | 누적 피해고사목 | 절대적 피해량 |
| 밀도 | 누적피해부담_100ha | 소나무류 면적 대비 부담 |
| 지속성 | 관측피해격자 반복관측비율, 장기지속격자수 | 반복·만성 여부 |

규모가 큰 지역, 면적 대비 부담이 큰 지역, 반복성이 높은 지역은 서로 다르며
(누적 피해부담 상위 15개 중 5개는 절대 건수 상위에 없음)
필요한 지원 유형도 달라진다.

### 2-3. 후속 분석 연결

- **CH2 취약도**: `장기지속격자수_100m`, `관측피해격자_반복관측비율(%)`,
  `누적피해부담_100ha`를 시군구 단위 설명변수로 사용할 수 있다.
- **CH3 우선지원**: 현재 피해등급과 과거 반복관측 이력을 교차해 대상을 선정한다.
  단, 과거 이력이 현재 피해의 원인임을 의미하지 않으므로 중첩 여부만 기재한다.

### 2-4. 자료 측면의 제약

| 제약 | 영향 | 필요 조치 |
|---|---|---|
| 2022.5~2023.4 이후 공개 원자료 불완전·부재 | 최신 공간분포 분석 불가 | 시군구별 확정 통계 확보 |
| 시군구별 피해본수 비공개 | 등급 외 정량 비교 불가 | 정보공개청구 |
| 경계파일 수록 범위 제한 | 일부 시군구 지도 표시 불가 | 전국 시군구 경계 확보 |
| 소나무류 면적 기준연도 불일치 | 면적 대비 지표의 시점 차이 | 분자·분모 기준연도 정렬 |
| 좌표계 저일치 기관 존재 (자료 비중 1.52%) | 해당 기관 지역 좌표 신뢰도 | 확대 표본 재검증 |
