01. 전체 아키텍처 — 왜 모형을 하나로 합치면 안 되는가

지수에 과거이력·공간확산을 넣으면 AUC는 0.97까지 뛰지만, 그 순간 지수는 "구조적으로 왜 취약한가"가 아니라 "작년에 터진 곳이 올해도 터진다"는 걸 재확인하는 물건이 된다. 그러면 "취약성에 기여한 변수를 바탕으로 맞춤형 예산을 설계한다"는 프로젝트의 핵심 스토리 자체가 무너진다 — 기여 변수가 전부 "작년 발생 여부"가 돼버리니 정책적으로 할 말이 없어진다(예산을 더 준다고 작년 발생 이력이 바뀌진 않으니까). 그래서 역할을 분리한 2엔진 구조를 쓴다.

Model 1 · 측정도구

구조적 취약성지수

0.58–0.64AUC — 낮지만 정직
  • 투입: 노출도·기후·인위적확산·대응역량 (정책개입 가능한 변수만)
  • 역할: "왜 취약한가" 설명 → 정책 설계 엔진
  • 산출물: 시군구별 도메인 기여도 분해
Model 2 · 예측도구

조기경보모형

0.97AUC — 검증·신뢰성 확보용
  • 투입: Model 1 전체 + 전년도 발생이력·인접확산(t-1)
  • 역할: "이 프레임워크가 실제로 맞다"는 신뢰성 과시
  • 산출물: 발생확률 랭킹(단기 예찰자원 배치용)
피치 화법 심사 발표에서 "AUC가 왜 낮냐"는 질문에 "저희는 정책개입 가능한 구조변수만 썼고, 여기에 과거이력을 더하면 AUC 0.97까지 나온다는 것도 검증했습니다 — 다만 그건 '작년에 터진 곳이 또 터진다'는 당연한 결과라 정책설계엔 안 씁니다"라고 먼저 선수치는 답변이 가능해진다. 이게 오히려 방법론적 성숙도를 어필하는 포인트가 된다.

Model 1이 실제로 하는 일 — 기여도 분해가 핵심

취약성지수는 도메인 점수의 가중합이므로, 시군구별로 어느 도메인이 점수를 밀어올렸는지 자동으로 분해된다.

지수_i  =  0.25×노출도_i  +  0.25×기후위험도_i  +  0.25×인위적확산_i  +  0.25×지자체대응역량_i  (역량 항은 구성 단계에서 이미 역방향 부호 반영, 결합 시 추가 반전 없음)

완도군의 지수가 높다면, 그게 "노출도 때문"인지 "대응역량이 낮아서"인지 도메인별 기여분을 가중치×도메인점수로 그대로 계산할 수 있다. "얼마를 더 줄까"가 아니라 "어떤 종류의 지원이 필요한가"까지 구분해서 제안하는 게 이 프로젝트의 차별화 포인트다 — 대부분의 팀은 "취약한 곳에 예산 더"까지만 가고, 유형 매칭까지 가는 팀은 드물다. (단, 이 1축 기여도만으로 정책유형을 만들면 순환논리 문제가 생기는데, 이건 §03에서 2축 구조로 해결한다.)

정책 제안까지 이어지는 흐름

  1. 취약성지수 산출 (Model 1) → 시군구별 기여도 분해 완료
  2. 배분갭 진단 → "위험 대비 예산이 R²=4%밖에 설명 안 됨" — 현재 배분이 위험을 거의 반영 못한다는 문제 제기 완료
  3. 배분공식 시뮬레이션 → 완도군·의성군처럼 위험최상위인데 예산 0원인 곳을 구체적으로 지목, 재배분 시뮬레이션 완료
  4. 기여도 기반 지원 유형 매핑 → 같은 "부족" 판정이라도 지자체마다 다른 처방 제안 §03 참고
  5. 조기경보모형 (Model 2, AUC 0.97) → "이 프레임워크 전체가 실제로 검증됐다"는 신뢰도 보강용 부록 정식 섹션화 예정

02. 이론적 근거 — 두 모형은 완전히 다른 기준으로 평가해야 한다

Model 1의 정체는 "예측모형"이 아니라 측정도구다. 심리측정학에서 관측 안 되는 잠재특성(construct)을 여러 지표로 근사하는 것과 같은 문제라서, 이론적으로 맞는 모형·지표도 예측모형과는 다르게 골라야 한다. Model 2는 반대로 완전한 예측/의사결정 도구다. 같은 잣대(AUC 하나)를 두 모형에 들이대면 안 된다는 게 이 절의 핵심.

Model 1 · 측정도구로서의 이론

Y 분포 → 패널구조 → 표준오차 → 가중치

  • Y 분포: 구조적 영과잉이라 OLS·Tobit 부적합. Tobit은 "발생"과 "발생시 크기"가 같은 잠재변수의 검열이라 가정하는데, 두 메커니즘(노출·전파 vs 대응역량)이 다를 수 있음 → Cragg(1971) two-part/hurdle이 이론적으로 더 맞음
  • 패널구조: FE는 검증 대상인 between 변이를 지워버리는 자기모순, RE는 외생성 가정이 비현실적 → Mundlak(1978) CRE가 Hausman 딜레마의 표준 해법
  • 표준오차: 229군집은 cluster-robust(Moulton 1990) 근거 충분, 31군집 하위표본은 pairs cluster bootstrap(Cameron & Miller 2015)이 더 안전
  • 가중치: LMG/Shapley(Lindeman-Merenda-Gold 1980)는 저신호 도메인에서 불안정 + 역인과 도메인엔 적용 불가 → OECD 합성지표 편람(2008)이 권고하는 이론지향 동일가중이 정답
Model 2 · 예측도구로서의 이론

이론적 앵커 → 모형군 → 동적패널 유의점

  • 이론적 앵커: Held–Höhle–Hofmann(2005) 감시통계 프레임워크의 endemic(구조적 공변량)+epidemic(자기시차+공간시차) 분해와 Model1/Model2 구조가 개념적으로 동일 — "임의로 지수를 두 개 만들었다"가 아니라 "확립된 감시모형 이론의 표준 분해"로 프레이밍 가능
  • 모형군: binary 로지스틱은 강도 정보를 버림 → Poisson/Negative Binomial(log 소나무림면적 오프셋)이 더 적합, 산림병해충의 군집성(overdispersion) 때문에 NB 권장
  • 예측식: log(λ_it) = endemic(Model1 구조변수) + φ·log(Y_i,t-1+1) + ψ·log(인접시군_Y_i,t-1+1) — hhh4 사양과 이론적으로 일치
  • 동적패널 유의점: 자기시차(lagged DV)는 단기패널(T=8)에서 Nickell(1981) bias 발생 — 이론적 해법은 System GMM(Arellano-Bond/Blundell-Bond), 공모전 범위에선 이 편향을 인지하고 있다는 것 자체가 방법론적 성숙도. Model1의 CRE 장치를 그대로 재사용할 근거는 없음(목적이 다름)

Model 1 핵심 판정지표 (우선순위 순)

  1. between 계수의 부호·유의성(훈련·홀드아웃 모두) — 측정도구의 "수렴타당도", 예측정확도보다 우선
  2. 두 가중치 버전 간 순위상관 — 방법론적 강건성
  3. between 계수의 시간적 안정성(rolling-origin) — "그 해만 우연히 유의했나" 확인
  4. 십분위 실적표(단조성) — calibration에 가까운 확인용, 정밀예측 지표 아님
  5. AUC/Spearman — 필요조건("무작위보다 낫다")이지 목표 자체 아님. R²는 부차적

Model 2 핵심 판정지표 (완전히 다른 지표군)

  1. 진짜 walk-forward(rolling-origin) out-of-sample 정확도 — 훈련기간 정보만으로 미래를 맞히는지가 유일한 기준
  2. Calibration(Brier score, reliability diagram) — 실제 배치 임계값을 정하려면 예측확률 자체가 정확해야 함
  3. Precision@K / Recall@K — 제한된 예찰자원 하에서 상위 K곳 포착률(미탐지≫오탐지 비용 반영)
  4. Nested model 유의성 검정(우도비검정 또는 DeLong's test) — "AUC가 커졌다"가 아니라 epidemic 성분 추가가 통계적으로 유의한지 정식 검정

03. 유형화 설계 — 2축으로 쪼개는 게 핵심

역량 도메인 z-score로 "부족형"을 만들면 동어반복(순환논리)이 된다. 이를 풀려면 "왜 위험한가" 축과 "예산이 맞는가" 축을 아예 분리된 두 축으로 만들어야 한다 — 하나의 유형 리스트에 원인과 결과를 섞으면 안 된다.

축 A · 위험요인 우세형

위험지수 = 노출도 + 인위적확산만

  • 임계치 룰: 노출도_점수 − 인위적확산_점수 차이가 ±0.5SD 넘으면 우세형, 그 안이면 복합형
  • 기후위험도는 축에서 제외 — 지자체별 참고각주로만 병기(LMG 기여 0.5%, 방향 불안정을 이미 자인)
  • 저위험 지자체(위험지수 < 중앙값)는 유형화 대상에서 제외 → "저위험형"으로 별도 처리
축 B · 배분 적정성

Model B 1단계 배분갭 잔차 사용

  • 역량 도메인 z-score가 아니라 회귀잔차(위험 대비 예산의 편차) 사용 — 독립적인 통계적 진단
  • 하위/중위/상위 3분위 또는 유의성 기준으로 부족/적정/과다 구분

두 축을 교차하면 3×3(저위험 제외 시 2×3) 매트릭스가 나오고, "부족" 열에만 실제 신규예산 처방을 매핑한다.

04. 예상 심사질문 대응 로직

이미 보고서 안에 답이 다 있는 것들이라, 실제로 필요한 건 질문→답 매핑을 미리 정리해두는 것뿐이다.

예상 질문준비된 답변의 핵심
AUC가 왜 이렇게 낮나(0.58~0.64)?정책개입 가능한 구조변수만 씀. 확산이력 넣으면 0.97 나오는 것도 검증했지만 그건 "작년 터진 곳이 또 터진다"는 재확인이라 정책엔 못 씀 (Model 2로 선수치기)
R²=8%로 신뢰할 수 있나?검증 대상은 between(지자체간 만성적 줄세우기)이지 연도별 변동 예측이 아님 — 맞춤형 예산배분은 정확히 between 질문(§4.2 근거)
기후위험도 기여가 거의 0인데 왜 넣었나?지수엔 이론적 구성요소로 유지, 동일가중을 주지수로 채택한 이유가 바로 이것(LMG 불신). 유형화 단계에선 제외
예산 변수 부호를 억지로 뒤집은 거 아닌가?역인과가 §6.3 타겟팅 역전 결과로 실증됨. 사전에 문서화된 이론적 원칙 적용이지 사후 자의적 조정 아님
배분갭이 인과관계 증거인가?아니다, 명시적으로 기술적 진단+안면타당성 수준으로 프레이밍(§6.1에서 인과추정 보류 명시). 우선순위 신호로만 사용
