CH2 방제취약성지수 · 맞춤형 예산배분 모델링 - 스크립트 모음
================================================================

실행 순서(의존관계 있음 - 반드시 이 순서대로):

1. final_modeling.py
   - 표본 정의(면적=0 16행 제외), 핵심변수 결측 처리
   - 방제취약성지수 산출(동일가중/LMG 실증가중 2버전)
   - 모형 A: CRE(Mundlak) 2부문모형(발생여부 로지스틱 + 발생시 크기 OLS)
   - 출력: output/모델링/방제취약성지수_산출결과.csv, 모형A_로그.txt

2. model_b_stage1.py  (1번 출력 필요)
   - 배분갭 진단: 위험지수(역량도메인 제외) vs 실제예산 회귀
   - 출력: output/모델링/배분갭_진단결과.csv, 배분갭_로그.txt

3. model_b_stage3.py  (1번 출력 필요)
   - 배분공식 시뮬레이션(하한/상한 제약 반영, 재배분 시뮬레이션)
   - 출력: output/모델링/배분공식_시뮬레이션결과.csv, 배분공식_로그.txt

4. national_response_robustness.py  (1번 출력 필요)
   - 국가대응수준 보조모형(31개 시군구, selection-on-outcome 확인,
     군집 페어 부트스트랩)
   - 출력: output/모델링/국가대응수준_보조모형_로그.txt

5. early_warning_test.py  (1번 출력 필요)
   - 실험: t-1 시차 확산이력/공간시차 변수 추가 시 AUC 변화 확인
   - 구조적 취약성지수와는 목적이 다른 별도 참고모형(조기경보용)
   - 출력: 콘솔 출력만(별도 저장 파일 없음)

원본 데이터/사전:
  output/CH2_전체병합패널_5도메인_2016_2023.csv
  output/변수사전_역할태그.csv (팀 공식 변수 역할 태그)

이 스크립트들이 참조하는 상위 데이터 준비 파이프라인(이번 모델링 세션 이전 산출물):
  scripts/merge_5domains.py, scripts/eda_병합패널.py, scripts/build_변수사전.py
