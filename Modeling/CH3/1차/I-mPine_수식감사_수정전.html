F01

Within-year Z-score 표준화

model1_v4_final.py:79
zit = (xit − μt) / σt # i = 시군구, t = 연도. 연도별로 평균·표준편차를 구해 표준화 # ddof=0 (모집단 SD 사용)
이론 근거 있음

이론적 근거

패널 데이터에서 시간 추세(trend)와 시점 효과(period effect)를 제거하기 위한 표준 방법. 기후변수처럼 연도별 전국 수준이 다른 변수에서 "그 해 평균 대비 얼마나 높은가"를 측정합니다.

참고문헌: Wooldridge (2010) Econometric Analysis of Cross Section and Panel Data, §10.5 — within-group transformation. 환경·역학 분야에서 연도 내 상대순위 사용은 보편적(예: CDC의 BMI z-score).

현재 문제

  • ddof=0 (모집단 SD) 사용 — 표본인데 모집단 취급. n=222에서 차이 미미하지만 학술적으로는 ddof=1이 표준
  • 연도별 n이 동일하지 않음(표본 카스케이드로 일부 연도에 시군구가 빠짐) — z-score의 비교 가능성에 미미한 영향

개선 방향

ddof=1로 변경(1줄). 또는 백분위 변환(percentile rank)으로 교체하면 정규성 가정 없이도 비교 가능하고, 이상치에 강건함. 계획서 §4.1도 백분위를 처방하고 있음.

현재 정확도

표준화 자체는 정보 손실 없는 단조변환이므로 "정확도" 개념이 적용되지 않습니다. 다만 순위 보존 여부는 100% — 원값의 순위가 z-score에서도 동일.

도메인 점수 부호 결정

model1_v4_final.py:82–95
direction = np.sign(corr(x, Y)) # Y = log_피해밀도. Y와의 상관 부호에 따라 +1 또는 −1 # 예: 연강수량 r=+0.036 → direction = +1 # 예: 대응예산 r=+0.255 → direction = −1 (역부호 고정)
순환 검증 위험 일부 사전고정 / 일부 데이터결정

이론적 근거

혼합. 대응역량(−1)·노출도(+1)는 사전 이론에 따라 고정. 기후위험도(연강수량·GDD)는 np.sign(sign_check[...])로 Y와의 상관에서 데이터 기반으로 결정됩니다.

문제: 결과변수(Y)를 보고 부호를 정한 뒤, 같은 Y로 지수-피해 관계를 검증하면 순환 검증(circular validation)이 됩니다. 특히 연강수량은 r=+0.036으로 순수 노이즈 수준인데 이것으로 부호가 결정되었습니다.

이론적으로 강수량은 소나무 수분 스트레스를 완화하므로 피해와 음의 관계(−1)가 예상됩니다. 하지만 재선충 매개충(솔수염하늘소) 활동은 습윤 조건에서 증가한다는 연구도 있어(Togashi & Shigesada, 2006) 방향이 자명하지 않습니다.

현재 문제

  • 연강수량의 부호가 노이즈(r=+0.036)에서 결정됨 → 표본이 바뀌면 부호가 뒤집힘
  • AUC 0.581도 이 순환 덕분에 상방 편향된 값
  • GDD는 r=+0.152로 이론과 부합(고온 → 매개충 세대수 증가)하지만, 역시 데이터에서 결정

개선 방향

모든 부호를 사전 이론으로 고정하고, 부호 정당성을 문헌으로 뒷받침:

변수이론 부호근거
소나무류_면적비율+1숙주 밀도 ↑ = 감염 확률 ↑ (기본 역학)
연강수량−1 (또는 제외)수분 스트레스 완화; 직접 효과 불명확하면 제외가 더 안전
GDD+1솔수염하늘소 발육 적산온도. Togashi (2004)
대응예산−1 (고정)이미 고정. 역인과 문제는 별도
원목업체수+1 (변경 필요)현행 −1은 "업체 적음 = 위험 높음"이 되어 라벨과 모순

이론적 근거

Frisch-Waugh-Lovell 정리. 다중회귀에서 한 변수의 효과를 보기 위해 다른 변수의 효과를 먼저 제거하는 것은 partialling out과 동치입니다. 면적이 크면 도로도 많고 업체도 많으므로, 면적의 교란(confounding)을 제거하는 표준 접근입니다.

현재 정확도

CRE(Mundlak) 2부문모형

model1_v4_final.py:111–145
1부문(발생여부): logit(P(Yit>0)) = α + βw·Indexit + βb·Index̄i + εit 2부문(발생시 크기): E[Yit | Yit>0] = α + βw·Indexit + βb·Index̄i + uit # Index̄ᵢ = 시군구 i의 시간 평균 (Mundlak device) # β_w = within 효과 (같은 지자체 내 시간변동) # β_b = between 효과 (지자체 간 만성적 차이) # 클러스터 SE (시군구 수준)
이론 근거 있음 구현 오류 있음

이론적 근거

Correlated Random Effects (Mundlak, 1978). FE(고정효과)가 시불변 변수를 제거하는 대신 RE에 그룹평균을 추가해 between/within 효과를 분리. Chamberlain (1982)의 일반화. 재선충 맥락에서 "만성적 취약성(between)"과 "연도별 변동(within)"을 구분하는 데 적합합니다.

2부문모형(Two-part model): 의료비·보험 분석에서 표준 — "발생여부"와 "발생시 크기"를 분리. Manning et al. (1987), Duan et al. (1983). 피해밀도가 0인 관측이 60%이므로 단일 OLS보다 적합합니다.

현재 문제 — 치명적 구현 오류

run_two_part(holdout, "구조적취약성지수", "홀드아웃")은 홀드아웃에서 새로 적합(fit)합니다. 즉 "표본외 검증 AUC 0.564"는 실제로는 표본 내 값입니다.

Model2 스크립트의 add_frozen_gm()처럼 훈련 계수를 고정한 채 홀드아웃에서 예측만 해야 합니다.

between βpwithin βpAUC

Between 유의(만성 취약성 포착) / Within 비유의(단기예측 불가) / AUC ≈ 0.57(무작위 0.5 대비 +0.07)

정확도를 높이는 방법

  1. Frozen-gm 적용(Model2처럼): AUC가 더 떨어질 수 있지만 정직한 표본외 수치
  2. Y_bin 임계값 상향: "1본 이상" → "상위 25%" → 기저율이 낮아져 AUC 개선 기대
  3. 공간 래그 추가: 인접시군구 전기 피해밀도. Model2에서 비유의했지만 Model1과 사양이 달라 재시도 가치 있음
  4. 혼합효과 로지스틱(GLMM): CRE보다 엄밀한 랜덤효과 처리. statsmodels.MixedLM 또는 R의 lme4::glmer

예산 배분갭

model1_v4_final.py:149–166
위험지수i = (노출도 + 기후위험도 + 인위적확산) / 3 # 대응역량은 순환논리 방지를 위해 제외 배분갭i = 평균예산i − (α̂ + β̂ × 위험지수i) # OLS(평균예산 ~ 위험지수)의 잔차 # 양수 = 위험 대비 예산 과다, 음수 = 과소
표준 잔차 분석 해석 주의 필요

이론적 근거

OLS 잔차를 "불일치(mismatch)"로 해석하는 것은 재정 분석에서 표준적입니다. Boadway & Shah (2009) Fiscal Federalism에서 교부금의 수평적 형평성을 진단할 때 사용합니다.

현재 문제

  • R² = 2.39%. 위험지수가 예산 분산의 2.4%만 설명 → 예측값이 거의 상수 → 잔차 ≈ 원변수(예산). corr(배분갭, 평균예산_log) = 0.988
  • 예산 0 = 구조적 0. 재선충 예산이 0인 64곳은 "병이 없어서 배정 안 한 것"인데, 이것이 "과소배분"으로 판정됨
  • 역인과. 예산은 피해의 결과(r=+0.255). 피해가 있어야 예산이 옴

개선 방향

  1. 2부문 처리: (a) 예산 배정 여부 로지스틱 (b) 배정된 경우만 수준 OLS. 배분갭은 (b)에서만 정의. 미배정은 별도 범주
  2. 통제변수 추가: budget ~ 위험지수 + log_소나무림면적 + 전기_피해량 + C(시도) → R² 상승 → 잔차가 진짜 "불일치"에 가까워짐
  3. IV(도구변수): 시차예산 또는 배분공식 규칙요소를 도구변수로 → 역인과 통제

이론적 근거

개선 방향

우선지원 점수 — 계획서 처방

분석계획서 §4.1
Priority = 0.60 × RiskPct + 0.40 × UnderfundPct # RiskPct = 역량 제외 위험지수의 연도내 백분위 (0~1) # UnderfundPct = (−배분갭)의 연도내 백분위 (0~1) # 등급: S(상위5%) / A(10%) / B(20%) / C(80%) / D(하위20%)
계획서 처방 백분위 = 분포 비의존 표준화

이론적 근거

  • 백분위 변환: 서로 다른 단위의 지표를 0~1 동일 척도로 변환. F09의 단위 불일치를 구조적으로 해결
  • 0.60/0.40 가중치: "위험이 우선, 예산 부족은 보조" 원칙. 계획서는 0.50/0.50, 0.70/0.30 민감도도 요구
  • 역량 제외: "적은 예산→취약점수↑→추가 예산 배분→더 적은 예산"의 순환논리 차단
  • S/A/B/C/D: 정책적으로 우선순위 그룹을 명확히 구분. 예산 규모에 따라 S만 / S+A / S+A+B 선택

적용 결과

Spearman(priority, 재발확률) = +0.068 (−0.48 → +0.07). Spearman(priority, 위험지수) = +0.858. 서울 자치구 TOP30 내 8곳→1곳. 다만 완도군 여전히 1위 (인위적확산 도메인 라벨 문제, F02 참조).

추가 개선

계획서 자체에 재발위험확률이 우선순위 산식에 포함되지 않음. 재발확률은 04번(시뮬레이션)의 urgentList에서만 사용. 이것이 Spearman이 +0.07에 그치는 이유. 재발확률을 3번째 축으로 추가하면 F11이 됩니다.

F11

우선지원 점수 — 검증보고서 제안

검증보고서 §2-A / P0_1_fix_priority_score.py
priority = 0.5 × z(구조위험지수) + 0.5 × z(재발위험확률) + 0.15 × z(−배분갭) # 모집단: 재발위험확률 > 0.05 또는 index_main > 0.3
Ad-hoc 제안 정량적 근거 불충분

이론적 근거

부족. 이 산식은 검증보고서가 "피드백 패치"로 제안한 것으로, 다음 문제가 있습니다:

  • 가중치 0.5/0.5/0.15의 합이 1.15 ≠ 1.0. 정규화되지 않아 해석이 불분명
  • 0.05, 0.3 임계값의 근거 없음. "팀 논의 필요"라고 적혀 있지만, 이 값이 어디서 왔는지 설명이 없음
  • z-score 사용: 백분위보다 이상치에 민감. 재발위험확률은 0.99995~0.001로 극단적 분포 → z-score가 왜곡됨
  • 재발위험확률 직접 투입의 문제: Model2가 기준모형(연속발생연수 단독 AUC 0.918)보다 못한데(0.911), 그 예측값을 50% 가중으로 사용하는 것이 정당화되지 않음

개선 방향 — 이 산식 대신

  1. 계획서 F10을 기본으로 사용하되, 재발위험확률은 urgentList 교차조건으로만 활용 (계획서 원래 설계)
  2. 재발확률을 산식에 넣으려면: 0.50 × RiskPct + 0.30 × UnderfundPct + 0.20 × RecurrencePct처럼 합 = 1.0이 되게 하고, 가중치 선택 근거를 명시
  3. 모집단 임계값은 소나무림면적 ≥ 300ha(현행 순위 분석의 기존 기준) 또는 2017~2022 중 1회 이상 발생처럼 정책적으로 정의 가능한 기준으로
  4. 가중치 민감도: 0.60/0.20/0.20, 0.40/0.40/0.20, 0.50/0.30/0.20 등 3~5개 대안을 부록에 → 순위 TOP20 중복률로 안정성 검증
