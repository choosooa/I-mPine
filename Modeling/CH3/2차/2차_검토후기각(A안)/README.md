# 2차_검토후기각(A안)

인위적확산 도메인 부호를 +1로 반전한 안(A안)의 2차 당시 구현물입니다. 당시에는 완도군 순위 개선(6위→96위)과 모형 성능 개선(홀드아웃 AUC 0.594→0.616, 배분갭 R² 3.40%→4.78%)을 근거로 채택 후보였습니다(구 폴더명: `2차_최종채택(A안)`).

**3차 재검증(2026-07-31)에서 최종 기각되었습니다.** 위 성능 개선 수치가 CH2 7차 최종판이 아니라 폐기된 3차 패널(도로소나무비율 변수 포함) 재구현 파이프라인에서 나온 값이었고, CH2 7차 최종판 원본 스크립트(`model1_final.py`)로 재실행하면 재현되지 않는다는 사실이 확인됐습니다. 실제 피해밀도와의 상관도 부호 반전 시 오히려 하락합니다(0.407→0.361).

최종 채택안(B안)은 `Modeling/CH3/3차/3차_구현_B안(최종로직)/`, 근거는 `Modeling/CH3/3차/CH3_분석보고서_3차.docx` §2.1을 참고하세요. 이 폴더는 비교·기각 사유 기록용으로만 보관합니다.
