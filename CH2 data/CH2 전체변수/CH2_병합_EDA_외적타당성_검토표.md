# CH2 병합 전 EDA 및 외적 타당성 검토표

## 0. 현재 파일 구조 1차 진단

| 블록 | 파일 | 행 x 열 | 연도 범위 | 병합키 후보 | 즉시 주의점 |
|---|---:|---:|---:|---|---|
| 국가대응수준 | `CH2_국가대응수준_최종변수선정.csv` | 1832 x 15 | 2016-2023 | `연도+시도+시군구` | `연도+시군구`는 중복. 예산계열 결측률 약 86-89%라 결측 의미 확인 필수 |
| 기후위험도 | `CH2_기후위험도_최종변수선정.csv` | 2000 x 16 | 2016-2023 | `연도+sigungu_cd`, `연도+시도+시군구` | 기상관측 기반 변수 결측 약 1.4-1.5%. 관측소 거리/완전성 필수 검토 |
| 노출도 | `CH2_노출도_최종변수선정.csv` | 1832 x 12 | 2016-2023 | `연도+시도+시군구` | 결측 0%이나 1832행 패널. 2000행 패널과 병합 시 제외 단위 발생 |
| 인위적확산 | `CH2_인위적확산_최종변수.csv` | 2000 x 6 | 2016-2023 | `연도+시도+시군구명` | 시군구 컬럼명이 다름. 도로/주거지 변수 결측 약 1.2% |
| 지자체대응역량 | `CH2_지자체대응역량_최최종.csv` | 2000 x 22 | 2016-2023 | `연도+시군구코드`, `연도+시도+시군구` | 예산/법인 기반 지수 결측 큼. `연도+시군구` 단독 병합 금지 |

엄격 기준: 최종 병합키는 가능하면 행정구역 코드 기반이어야 한다. 코드가 없는 블록은 `시도+시군구`로 임시 병합하되, 코드 매핑표를 붙여 최종적으로 `연도+시군구코드`로 검산한다.

## 1. 병합 전 필수 검토

| 영역 | 검토 항목 | 통과 기준 | 실패 시 조치 |
|---|---|---|---|
| 파일 버전 | 최종 파일명이 맞는가 | 분석 대상 5개 파일 경로와 생성일 기록 | 동일명/중복 파일 비교 후 하나만 채택 |
| 인코딩 | 한글 컬럼/값 깨짐 여부 | 모든 파일 정상 로드 | `utf-8-sig`, `cp949` 중 확정 인코딩 기록 |
| 행 수 | 파일별 패널 크기 차이 | 2000행 또는 의도된 1832행 사유 설명 가능 | 빠진 시군구-연도 목록 산출 |
| 연도 범위 | 모든 파일 2016-2023인지 | 연도 8개 모두 존재 | 누락 연도 보간 금지, 결측으로 명시 |
| 공간 단위 | 시군구 기준 일치 여부 | 행정구역 단위/폐지·통합 처리 기준 일치 | crosswalk 작성 |
| 병합키 | `연도+시군구` 단독 사용 여부 | 사용 금지. 동명이군 존재 | `연도+시도+시군구` 또는 코드키 사용 |
| 중복키 | 병합키별 중복 | 각 파일 중복 0 | 중복 원인 분해 후 집계/제거 |
| 컬럼명 | `시군구` vs `시군구명`, 코드명 통일 | 최종 표준명으로 변환 | rename map 작성 |
| 단위 | 원, ha, %, km, log 변환 확인 | 변수명/메타데이터에 단위 명시 | 단위 변환 전후 컬럼 보존 |
| 원자료 보존 | 원변수와 가공변수 구분 | 원자료/로그/표준화 변수 역할 분리 | 데이터 사전 작성 |

## 2. 병합 품질 검토

| 검토 항목 | 산출물 | 엄격 판정 기준 |
|---|---|---|
| left join vs inner join 비교 | 병합 방식별 행 수, 결측 수 | 분석 목적상 제외되는 단위가 명확해야 함 |
| 병합 전후 행 수 | 단계별 row count 로그 | 의도치 않은 행 증식 0 |
| 병합 실패 목록 | 파일별 unmatched key list | 미매칭 키를 모두 설명 |
| 병합 후 중복 | `연도+시군구코드` 중복 수 | 0 |
| 결측 증가 | 병합 전후 변수별 결측률 변화 | join 때문에 생긴 결측 별도 표시 |
| 1832 vs 2000 패널 차이 | 누락 단위/연도 표 | 제외가 표본편향을 만들지 검정 |
| 행정구역 동명이인 | 중구, 남구 등 중복명 목록 | 코드 없이 병합한 결과 사용 금지 |
| 시도명 표준화 | 광역명 표기 비교 | 서울/서울특별시 등 통일 |

## 3. 전체 EDA 검토

| 영역 | 해야 할 분석 | 봐야 할 이상 신호 |
|---|---|---|
| 기술통계 | 평균, 중앙값, 표준편차, min/max, 분위수 | 음수 불가능 변수의 음수, 비율 0-100 초과 |
| 결측 구조 | 변수별/연도별/시도별 결측률 | 특정 연도·지역에 결측 집중 |
| 분포 | 히스토그램, boxplot, skew/kurtosis | 극단 왜도, 로그 후에도 긴 꼬리 |
| 이상치 | IQR, z-score, robust z, top/bottom 1% | 특정 시군구가 전체 결과 지배 |
| 연도 추세 | 변수별 연도 평균/중앙값 | 제도/자료원 변경에 따른 단절 |
| 공간 분포 | 시도별 평균, 지도 또는 heatmap | 인접 지역과 비상식적 불연속 |
| 상관 | Pearson/Spearman/Kendall | 같은 개념 중복 변수 상관 과다 |
| 다중공선성 | VIF, condition number | VIF 5 이상 주의, 10 이상 강한 경고 |
| 패널 구조 | within/between variance | 시간변화 거의 없는 변수의 패널모형 한계 |
| 스케일 | raw/log/per ha/표준화 비교 | 같은 의미 변수 중 중복 투입 위험 |

## 5. 외적 타당성 검정 메뉴

| 검정 | 목적 | 권장 종속변수 | 통과 기준 |
|---|---|---|---|
| 단순 상관 | 방향성 1차 확인 | 다음 해 신규 감염/피해밀도 | 이론 방향과 대체로 일치 |
| Spearman 상관 | 비선형/극단값 완화 | 피해 순위, 발생 여부 | Pearson과 방향 크게 모순 없음 |
| 분위별 차이 | 고위험 분위가 실제 피해 높은지 | t+1 신규 발생, t+1 피해밀도 | Q4/Q5가 Q1보다 유의하게 높음 |
| ROC-AUC | 발생/비발생 예측력 | 다음 해 발생 여부 | AUC 0.6 이상이면 약한 타당성, 0.7 이상 양호 |
| PR-AUC | 희소 발생 대응 | 다음 해 신규 발생 여부 | base rate 대비 개선 |
| 로지스틱 회귀 | 발생확률 설명 | t+1 발생 여부 | 부호/유의성/예측성 확인 |
| 음이항/포아송 | count형 피해 설명 | 감염목 수, 피해목 수 | overdispersion 검토 후 선택 |
| 고정효과 패널 | 지역 불변 특성 통제 | t+1 피해밀도 | 시군구 FE, 연도 FE 포함 |
| 시차 검정 | 시간 선후관계 확인 | t+1, t+2 피해 | 동시점보다 미래 예측력이 더 설득력 있음 |
| 민감도 분석 | 결과 안정성 확인 | 여러 피해 지표 | 변수 변환/표본 변경에도 결론 유지 |
| 공간 검정 | 공간 자기상관 확인 | 잔차, 피해밀도 | Moran's I 유의 시 공간모형 고려 |
| 표본 외 검정 | 일반화 성능 확인 | holdout 연도/지역 | train/test 성능 급락 여부 확인 |

## 6. 외적 타당성 검정 시 금지/주의

| 위험 | 왜 문제인가 | 대응 |
|---|---|---|
| 동시점 피해로 검정 | 원인과 결과가 섞임 | 설명변수 t, 결과변수 t+1 우선 |
| 예산변수 인과 해석 | 피해가 커서 예산이 늘었을 수 있음 | 대응역량은 예측/연관으로만 해석 |
| 코드 없는 이름 병합 | 동명이군 오병합 위험 | 코드 crosswalk 필수 |
| inner join만 사용 | 결측/누락 지역이 사라짐 | left/full join 진단 병행 |
| 결측을 0으로 일괄 대체 | 0과 미관측은 다름 | 결측사유 flag와 함께 처리 |
| 로그변수 raw변수 동시 투입 | 중복 정보/공선성 | 후보군별 하나만 선택 |
| 표준화 기준 혼합 | pooled vs 연도별 표준화 해석 다름 | 모델별 하나의 기준 유지 |
| 피해자료 포함 변수 누수 | 미래 결과를 설명변수에 포함할 수 있음 | 변수 생성 시점 audit |

## 7. 최종 분석 투입 전 통과 체크

| 번호 | 체크 | 상태 |
|---:|---|---|
| 1 | 최종 병합 데이터의 키는 `연도+시군구코드` 또는 동등하게 검증된 키다 | 미확인 |
| 2 | 병합 후 행 수가 기대 패널 수와 일치한다 | 미확인 |

| 5 | 모든 비율/거리/면적/금액 변수의 단위가 명확하다 | 미확인 |

| 10 | 결과 해석에서 인과와 예측/연관을 구분했다 | 미확인 |

## 8. 우선순위

1. 병합키 표준화: `시군구코드` 없는 파일에 코드 부여.
2. 1832행 파일과 2000행 파일의 차이 목록 생성.
3. 병합 후 행 증식/탈락 검산.
4. 결측 구조 분해: 특히 국가대응수준 예산계열, 지자체대응역량 예산/법인지수.
5. EDA 자동 리포트 생성.
6. 외적 타당성 검정: t+1 피해/발생 지표 기준으로 시작.
