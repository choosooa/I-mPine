# CH2 노출도 — 전국 229개 시군구 확장판 (2016~2025)

산출물: `CH2_노출도_전국_2016_2025.csv` (229개 시군구 × 10개년 = 2,290행)
(참고: 31개 표본 버전은 `CH2_노출도_2016_2025.csv`로 별도 보관)

## 1. 31개 → 전국 확장의 핵심 차이

31개 버전은 CH1 엑셀의 2023 스냅샷 비중을 전 연도에 고정 적용했다(같은 시도 내 모든 시군구가
동일한 증감률을 가짐). 전국 버전은 병해충 원자료를 직접 재처리해 **6개 연도(2017~2022)는
시군구별 실측값**을 확보했고, 나머지 4개 연도만 비중 추정을 사용한다 — 방법론적으로 더
탄탄해졌다.

### 원자료 재검증에서 발견한 것 (I-mPine 팀 CH1_EDA_최종.ipynb 교차검증)
31개 버전에서는 병해충 원자료(개별 감염목 point, `감염목구분=='감염목'` 기준, 파일명 기준
달력연도)를 CH1 시군구 스냅샷과 비교했을 때 창원시가 28배 어긋나는 등 신뢰할 수 없어 폐기했다.
그런데 I-mPine 팀 CH1 노트북이 **①`고사목구분=='피해고사목'` 필드를 쓰고 ②조사일자 기준
관리주기(5월~다음해4월)로 재집계**하자 전국 총량이 공식통계(`CH1_공식발생통계_2017_2025.csv`)
와 6개 관리주기 중 5개에서 오차 1% 미만으로 거의 완벽히 일치함을 확인했다. 이 수정된 방법으로
전국 229개 시군구를 재처리(`process_national_raw.py`)하니 국가 총량이 동일하게 검증되었다.

## 2. 연도별 데이터유형

| 연도(공식연도) | 유형 | 근거 |
|---|---|---|
| 2017~2022 | **실측** | 관리주기 2016~2021의 시군구별 피해고사목 원자료 집계. 국가 총량 대비 6개 중 5개 <1% 오차 |
| 2016 | 추정 | 원자료 기간 밖(2016.5 이전 미보유) → 시군구 평균비중 × 국가총량(초기 성장률로 역외삽) |
| 2023 | 추정 | 관리주기 2022는 국가통계 자체가 전년 대비 2.2배 튀어(2022→2023 실제 병해충 급증 반영으로 추정) 원자료 신뢰 불가 → 비중×실제 공식총량 |
| 2024, 2025 | 추정 | 원자료 기간 밖 → 비중×실제 공식총량(공식발생통계에 실제 존재, 외삽 아님) |

시군구 비중은 실측 6개년(2017~2022) 평균 비중을 사용. **한계**: 추정 4개년은 여전히 "그
시군구의 평균적 상대 비중"을 쓰므로 실측 연도만큼의 시군구별 변동성은 없음(단, 31개 버전보다
실측 연도가 훨씬 많아 개선됨).

## 3. 시군구 코드/이름 정합성 이슈와 처리

전국 확장 과정에서 아래 정합성 문제들을 발견하고 수정했다(`build_national_codebook.py` 참고):

- **강원특별자치도**: 병해충 원자료의 법정동코드가 51xx로 전환되어 있음(2023 전환 반영) —
  공식 법정동코드 전체자료(42xx)와 별도 크로스워크(`pest_code_51`) 구축
- **군위군**: 2023-07 경상북도 → 대구광역시 관할 변경. SGIS 2023 경계 기준(대구)으로 통일
- **세종시**: 법정동코드 자료상 "세종특별자치시"(시도명과 동일) vs SGIS "세종시" 표기 통일
- **인천 미추홀구**: 2018-07 개칭 전 이름("남구")이 남아있던 것을 통일
- **시군구명 시도 간 중복**: 강서구(서울/부산), 남구·동구·북구·서구·중구(여러 광역시),
  고성군(강원/경남) 등은 이름만으로 유일하지 않아, 전 과정에서 `시도명|시군구명` 복합키를
  사용함(중간에 이름만으로 잘못 합쳐지는 버그를 발견해 수정함 - 아래 4번 참고)

## 4. 변수별 방법 (31개 버전과 다른 점 위주)

| 변수 | 방법 |
|---|---|
| 전년도 피해본수 / 피해밀도 / 최근3년 증가율 | 31개 버전과 동일 로직, 시군구 시리즈만 위 하이브리드(실측+추정)로 교체 |
| 연속발생연수 | **[변경]** CH1 스냅샷 앵커가 전국 단위로는 없어, 2016년부터 자체 시계열로 순수 계산(연속 양수 연도 카운트, 끊기면 0으로 리셋) |
| 인접시군 피해밀도 | **[개선]** SGIS 실제 경계(2016~2023, 연도별)로 전국 229개 전체의 진짜 인접행렬을 만들어 대부분 실제 이웃으로 계산됨(2,290행 중 1,981행=86.5%). 실제 이웃이 없는 도서/변두리 지역(13.5%)만 centroid 최근접 3개로 대체 |
| 소나무류 면적/비율 | I-mPine 팀이 이미 만든 전국 임상도 기반 산출물(`sgg_pine_forest_area_all.csv`)을 재사용. 다만 연도별 변화 없이 고정값(전국 단일 스냅샷만 존재) — 31개 버전의 인위적 감소곡선보다는 안전하지만 시간 변동은 없음. 36개 시군구(대부분 도심 자치구)는 소스 파일 코드 불일치로 0 처리(`소나무류_결측` 컬럼에 표시) |
| 최근감염목과의 거리 | **[개선]** 위경도 근사 대신 SGIS 폴리곤의 실제 centroid(투영좌표 EPSG:5179) 간 유클리드 거리 사용 |
| 집단발생여부 | 31개 버전과 동일 로직(그 해 피해밀도 상위 30%+ 인접시군 평균도 상위 30%) |

## 5. 남은 한계
- 소나무류 면적은 여전히 단일 시점(임상도 갱신년도 다양) — 연도별 실제 변화 미반영
- 추정 4개 연도(2016,2023~2025)는 시군구별 실측 변동 없이 평균비중만 반영
- 소나무류 면적 36개 시군구 결측→0 처리(주로 도심 자치구, 실제 영향 미미하나 여수시·당진시·
  괴산군·음성군 등 일부는 실제 산림이 있는데 코드 불일치로 누락된 것으로 보임 — 후속 보정 필요

## 6. 재현 방법

```bash
python3 build_national_pine_area.py    # 전국 소나무류 면적 통합
python3 build_national_exposure.py     # 최종 CH2_노출도_전국_2016_2025.csv 조립
```
